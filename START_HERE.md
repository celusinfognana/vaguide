## 🎯 What to Try First

1. **Explore Home Dashboard**
   - See quick actions
   - Browse recent properties
   - View frequently used procedures

2. **Browse Properties**
   - Click "Properties" (left nav)
   - Search through 50+ properties
   - Filter by status, sort by name

3. **View Property Details**
   - Click any property (e.g., "AGI Holdings")
   - See 5 tabs: Overview, Rules, Procedures, Contacts, Info
   - Check property-specific rules

4. **Run an Interactive Workflow**
   - Click "Early Check-in" procedure
   - Click "Run" button
   - Follow step-by-step workflow
   - Select branches when prompted
   - Complete the workflow

5. **Try Global Search**
   - Press `Ctrl + K`
   - Search for: "early check-in"
   - See results across all properties
   - Use arrow keys to navigate, Enter to open

6. **Manage Favorites**
   - Click ⭐ star on any property/procedure
   - View in "Favorites" page (left nav)
